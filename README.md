# Turisteando — paquetes de ciudad

Este repositorio solo aloja los paquetes de ciudad de la app Turisteando, publicados como **Releases** (una por versión: `brujas-v1`, `gante-v1`…). No contiene código.

## Contenido y licencias

- Mapa: © OpenStreetMap contributors (ODbL), teselas de Protomaps.
- Textos de referencia: Wikipedia y Wikivoyage (CC BY-SA), Wikidata (CC0).
- Fotos: Wikimedia Commons; autor y licencia de cada foto en el manifiesto del paquete.
- Lugares para comer, beber y comprar: Foursquare Open Source Places (Apache 2.0).
- Fichas y audios "Turisteando con Clío y Chema": contenido propio.

Los paquetes no incluyen datos de Google ni de Tripadvisor.
